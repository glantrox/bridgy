# Security Policy

## Supported versions

Bridgy provides security fixes for its newest published release, including beta releases. If you use an older version, upgrade to receive fixes. [Bridgy releases](https://github.com/glantrox/bridgy/releases)

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub. Keep sensitive details out of public issues and discussions. [Report a vulnerability](https://github.com/glantrox/bridgy/security/advisories/new)

Include your Bridgy version (`bridgy --version`), operating system, the affected command or agent, and what happened. If the issue involves a conversation log, a short example with invented messages is usually enough. Remove credentials, private paths, and personal conversation content before submitting.

The maintainer reviews reports on a best-effort basis and replies in the private report thread. If a report is accepted, the maintainer will share updates as a fix becomes available and coordinate disclosure with you. If the report is declined, the maintainer will explain the decision in the same thread.
